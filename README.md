# TabGlow

タブ譜が読めなくても、光った場所を押さえれば弾ける — 初学者向けのタブ譜プレイヤーのプロトタイプ。

## 機能

- **TAB譜モード**: タブ譜の再生に合わせて指板上の押さえる場所が光る。次に押さえる場所は点線の円で予告。ギター(24フレット)/ベース対応、テンポ調整、タブの数字クリックで単音確認、自動スクロール
- **コードモード**: 定番コード11種の押さえ方を指板に表示(押さえる指を人・中・薬・小で表記)。クリックでストラム音を再生。12フレット表示
- 音はWeb Audio(Karplus-Strong撥弦シンセ)で生成。音源ファイル・バックエンド不要

サンプル曲: ドレミファソラシド → かえるのうた

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要・依存なしの単一HTMLファイル。

## 状態

フロントエンドの検証用プロトタイプ。この出来をもとに本実装(曲データの入力形式、リズム表現、奏法記号など)を検討中。
